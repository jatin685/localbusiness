GitHub Pages deployment

1. Extract this ZIP.
2. Upload the CONTENTS of this folder to the root of your GitHub repository (index.html must be at the top level).
3. In GitHub: Settings -> Pages -> Deploy from a branch -> choose main and /(root) -> Save.
4. Wait for the Pages deployment to finish, then open the published URL.

Note: This is a frontend demo. Login/register and contact forms do not connect to a backend. Business listings are stored in the visitor browser localStorage and are not shared across devices/users.
